# AI-haebom Curriculum

AI 해봄 동호회 컬리큘럼 공개용 GitHub Pages 저장소입니다.

이 저장소에는 공개 가능한 자료만 둡니다.

## Structure

```text
docs/
├─ index.html
├─ share-index.html
├─ session-01-start-page.html
├─ ...
└─ session-10-start-page.html
```

## GitHub Pages

GitHub Pages 설정은 아래처럼 사용합니다.

```text
Source: Deploy from a branch
Branch: main
Folder: /docs
```

공개 진입점:

```text
https://appletree0201.github.io/AI-haebom-curriculum/
```

## Safety Rule

- 내부자료, 개인정보, 민감정보를 넣지 않습니다.
- 원본 작업공간의 `raw/`, `wiki/`는 이 저장소에 넣지 않습니다.
- 공개 파일은 Private 작업 저장소에서 선별해 `docs/`로 복사합니다.
