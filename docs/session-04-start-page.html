오늘의 완료 기준

  • 실제 업무자동화가 반복 업무에서 출발한다는 점 이해

  • 확정 표현과 안전한 초안 표현 비교
  • 내 업무의 유사한 자동화 후보 떠올리기

오늘은 추천 메뉴 자동 선택이나 홈페이지 자동 등록은 다루지 않습니다.

4회차 현장 흐름

실제 작업본을 보면서 자동화가 어떤 작은 단계로 구성되는지 확인합니다.

업무 상황 보기 홈페이지 문의를 읽고 유형을 판단하는 반복 업무를 확인합니다.
질문 입력 정밀안전진단 보수교육 문의를 시연용 입력으로 사용합니다.
분류 확인 문의가 `승급교육 대상·대체인정`으로 분류되는지 봅니다.
초안 확인 답변 초안이 확정 표현을 피하고 확인 필요 정보를 담는지 봅니다.
내 업무 연결 내 업무에도 분류와 초안 작성으로 나눌 일이 있는지 찾습니다.
