3회차 현장 흐름

큰 요청을 바로 실행하지 않고, 질문을 되받아 계획으로 좁힌 뒤 첫 실행 요청만 만듭니다.

큰 요청 보기 `엑셀 명단을 보기 좋게 정리하고 싶어요`처럼 일부러 막연하게 시작합니다.
질문 되받기 바로 실행하지 말고 필요한 질문을 먼저 해달라고 요청합니다.
답변하기 부서별 요약표처럼 원하는 기준과 결과 형태를 답합니다.
계획 확인 입력, 작업, 출력, 확인 기준으로 계획을 점검합니다.
첫 요청 만들기 계획 전체가 아니라 첫 번째 단계만 실행 요청으로 바꿉니다.

집에서 할 일

내 업무의 큰 요청 하나를 골라 바로 실행하지 말고 질문부터 받아 봅니다.

  • 내 업무에서 큰 요청 하나를 적습니다.
  • `바로 실행하지 말고 필요한 질문을 해줘`라고 요청합니다.
  • AI가 되묻는 질문에 짧게 답합니다.
  • 계획을 입력, 작업, 출력, 확인으로 다시 봅니다.
  • 계획 중 첫 번째 단계만 실행 요청문으로 바꿉니다.
  • 반복되는 계획 방식은 나중에 스킬로 묶을 수 있다고 기억합니다.
