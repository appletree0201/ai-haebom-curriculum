# 1회차 문제 해결 FAQ

## 목적
이 문서는 1회차 설치와 기본 설정 중 자주 막히는 문제를 정리한 자료입니다.

각 항목은 `증상 -> 원인 -> 해결 순서`로 읽으면 됩니다.

## 1. VS Code 다운로드 사이트를 못 찾겠습니다
### 증상
검색 결과가 여러 개라서 어디에서 받아야 할지 모르겠습니다.

### 원인
검색 광고나 비슷한 이름의 사이트가 함께 보일 수 있습니다.

### 해결 순서
1. 브라우저 주소창에 `https://code.visualstudio.com/`을 직접 입력합니다.
2. 사이트 제목이 `Visual Studio Code`인지 확인합니다.
3. Windows 사용자는 `Download for Windows` 버튼을 누릅니다.

## 2. 설치했는데 VS Code가 안 열립니다
### 증상
설치 후 프로그램이 실행되지 않습니다.

### 원인
설치가 끝나지 않았거나, 실행 파일을 찾지 못했을 수 있습니다.

### 해결 순서
1. Windows 시작 메뉴에서 `Visual Studio Code`를 검색합니다.
2. 검색 결과가 나오면 실행합니다.
3. 실행되지 않으면 설치 파일을 다시 실행해 설치가 완료되었는지 확인합니다.
4. 회사 PC 보안 정책으로 막히는 경우 관리자나 담당자에게 문의합니다.

## 3. 메뉴가 영어로 나옵니다
### 증상
`File`, `Edit`, `View`처럼 영어 메뉴가 보입니다.

### 원인
한글 언어팩이 설치되지 않았거나, 설치 후 재시작하지 않았을 수 있습니다.

### 해결 순서
1. 왼쪽 `Extensions` 아이콘을 누릅니다.
2. `Korean Language Pack`을 검색합니다.
3. `Korean Language Pack for Visual Studio Code`를 설치합니다.
4. `Restart` 안내가 나오면 다시 시작합니다.
5. 다시 열린 뒤 메뉴가 한글로 바뀌었는지 확인합니다.

## 4. 확장 프로그램 검색 결과가 너무 많습니다
### 증상
`Python`, `Codex`, `Excel Viewer`를 검색했는데 결과가 여러 개 나옵니다.

### 원인
VS Code 확장 마켓플레이스에는 비슷한 이름의 확장이 많습니다.

### 해결 순서
1. 확장 이름을 먼저 확인합니다.
2. 제공자 이름을 함께 확인합니다.
3. `AI 해봄` 안내 화면이나 안내 자료와 이름 및 제공자가 같은지 비교합니다.
4. 확신이 없으면 임의로 설치하지 말고 질문합니다.

## 5. 확장 프로그램 설치 버튼이 보이지 않습니다
### 증상
검색 결과는 보이지만 `Install` 버튼이 보이지 않거나 설치가 안 됩니다.

### 원인
이미 설치되어 있거나, 회사 PC 보안 정책으로 막혔을 수 있습니다.

### 해결 순서
1. 버튼이 `Uninstall` 또는 `Disable`로 보이는지 확인합니다.
2. 그렇게 보이면 이미 설치된 상태입니다.
3. 설치 오류가 나오면 오류 메시지를 메모합니다.
4. 회사 PC에서 막히는 경우 관리자나 담당자에게 문의합니다.

## 6. 엑셀 뷰어 확장을 설치했는데 xlsx 파일이 바로 안 열립니다
### 증상
엑셀 파일을 눌렀는데 표처럼 보이지 않습니다.

### 원인
설치한 확장이 xlsx를 지원하지 않거나, 파일을 여는 방식이 다를 수 있습니다.

### 해결 순서
1. 설치한 확장 설명에서 `xlsx`, `csv` 지원 여부를 확인합니다.
2. 파일을 우클릭해 확장 프로그램으로 여는 메뉴가 있는지 봅니다.
3. CSV 파일은 일반 텍스트처럼 열릴 수 있다는 점을 기억합니다.
4. 1회차에서는 설치와 위치 확인까지만 완료해도 됩니다.

## 7. Codex 로그인이 안 됩니다
### 증상
Codex를 열었지만 로그인 화면에서 넘어가지 않습니다.

### 원인
계정 로그인, 브라우저 인증, 네트워크, 조직 권한 문제가 있을 수 있습니다.

### 해결 순서
1. 로그인 계정이 맞는지 확인합니다.
2. 브라우저 창이 열렸는지 확인합니다.
3. 회사 보안망에서 외부 로그인이 막히는지 확인합니다.
4. 오류 메시지를 그대로 메모합니다.
5. 같은 문제가 반복되면 담당자에게 화면을 보여줍니다.

## 8. 권한 메뉴가 헷갈립니다
### 증상
`기본 권한`, `전체 액세스`, `맞춤형(config.toml)` 중 무엇을 골라야 할지 모르겠습니다.

### 원인
권한은 Codex가 어디까지 파일을 보고 명령을 실행할 수 있는지와 관련됩니다.

### 해결 순서
1. 처음에는 `기본 권한`의 위치와 의미만 확인합니다.
2. `전체 액세스`는 더 많은 작업을 허용한다는 점만 기억합니다.
3. `맞춤형(config.toml)`은 나중에 설정 파일로 세부 조정할 때 보는 항목입니다.
4. 1회차에서는 권한 이름과 위치를 아는 것만으로 충분합니다.

## 9. 샘플 md 파일이 생기지 않습니다
### 증상
Codex에 요청했는데 `ai-haebom-practice.md` 파일이 보이지 않습니다.

### 원인
작업 폴더가 열려 있지 않거나, Codex가 다른 위치에 파일을 만들었을 수 있습니다.

### 해결 순서
1. `VS Code` 왼쪽 파일 목록에 작업 폴더가 열려 있는지 확인합니다.
2. Codex 응답에서 파일을 어디에 만들었다고 했는지 읽습니다.
3. 파일 목록을 새로고침하거나 폴더를 다시 확인합니다.
4. 요청을 더 구체적으로 바꿉니다.

```text
현재 VS Code에서 열려 있는 작업 폴더 안에 ai-haebom-practice.md 파일을 만들어줘.
```

## 10. 요청을 했는데 결과가 이상합니다
### 증상
원하는 파일이나 내용이 만들어지지 않았습니다.

### 원인
요청이 너무 길거나, 원하는 결과를 구체적으로 말하지 않았을 수 있습니다.

### 해결 순서
1. 한 번에 한 가지 일만 요청합니다.
2. 파일 이름, 위치, 형식을 구체적으로 말합니다.
3. 결과를 보고 한 줄만 다시 수정 요청합니다.
4. 처음부터 완벽하게 만들려고 하지 않습니다.
