# 2회차

## 오늘의 목표
- `AGENTS.md`가 무엇인지 이해한다.
- Codex가 작업 전에 읽는 기준 문서가 있다는 점을 안다.
- `AGENTS.md`는 자동으로 생기는 파일이 아니라 사람이 만들거나 Codex에게 만들어 달라고 요청할 수 있는 파일이라는 점을 안다.
- `skills`는 반복 작업을 위한 절차라는 점을 이해한다.
- 작업 기준과 반복 절차를 구분한다.

## 먼저 알아둘 말
`AGENTS.md`는 Codex에게 “이 작업공간에서는 이렇게 일해 달라”고 알려주는 문서입니다.

`skills`는 반복해서 쓰는 작업 절차입니다.

오늘은 두 개념을 외우는 날이 아닙니다.

Codex가 기준 없이 움직이는 도구가 아니라는 점을 이해하는 것이 핵심입니다.

## 왜 이걸 배우는가
AI에게 같은 요청을 해도 결과가 매번 달라질 수 있습니다.

작업 기준이 없으면 파일을 어디에 만들지, 어떤 말투로 설명할지, 무엇을 조심해야 할지 매번 다시 말해야 합니다.

`AGENTS.md`는 이런 기본 기준을 미리 적어 두는 문서입니다.

`skills`는 자주 반복하는 작업을 매번 새로 설명하지 않도록 절차로 묶어 두는 방식입니다.

## 핵심 개념 1: AGENTS.md
`AGENTS.md`는 작업 규칙 문서입니다.

예를 들어 아래 같은 내용을 적을 수 있습니다.

- 항상 한국어로 설명한다.
- 초보자도 이해할 수 있게 짧게 쓴다.
- 원본 파일은 함부로 수정하지 않는다.
- 결과물은 정해진 폴더에 저장한다.

개인 실습 폴더에는 처음부터 `AGENTS.md`가 없을 수 있습니다.

파일이 없다면 Codex에게 만들어 달라고 요청하거나 사람이 직접 만들 수 있습니다.

## Codex가 지침을 읽는 방식
Codex는 작업을 시작할 때 현재 작업공간에서 읽을 수 있는 지침을 참고합니다.

오늘은 아래 정도만 기억하면 됩니다.

1. 넓은 범위의 기본 지침이 있을 수 있습니다.
2. 현재 프로젝트의 `AGENTS.md`가 있을 수 있습니다.
3. 하위 폴더에 별도 `AGENTS.md`가 있으면 그 폴더 작업에 더 직접적인 기준이 될 수 있습니다.

즉, 어디에서 Codex를 실행하는지가 중요합니다.

작업 폴더를 잘못 열면 내가 기대한 규칙을 보지 못할 수 있습니다.

## AI 해봄 작업공간 예시
`AI 해봄` 예시 작업공간에는 동호회 자료를 만들기 위한 `AGENTS.md`가 미리 있습니다.

초보자는 전체 내용을 외울 필요가 없습니다.

아래 정도만 이해하면 됩니다.

- 루트의 `AGENTS.md`는 전체 작업공간의 기본 규칙입니다.
- `raw/AGENTS.md`는 원본 자료를 다룰 때의 규칙입니다.
- `Output/AGENTS.md`는 배부 자료와 결과물을 다룰 때의 규칙입니다.

이처럼 같은 작업공간 안에서도 폴더에 따라 필요한 규칙이 달라질 수 있습니다.

## 가장 쉬운 첫 AGENTS.md 예시
처음에는 업무 규칙보다 바로 눈에 보이는 규칙이 좋습니다.

예를 들어 아래처럼 말투 규칙을 넣어 볼 수 있습니다.

```md
# AGENTS.md

- 항상 한국어로 대답한다.
- 초보자도 이해할 수 있게 쉽게 설명한다.
- 답변 마지막에 "오늘도 해봄!"을 붙인다.
```

이 예시는 실제 업무 규칙이라기보다, `AGENTS.md`에 적은 내용을 Codex가 읽고 따르는지 확인하기 위한 연습입니다.

익숙해지면 말투보다 파일 저장 위치, 원본 보호, 설명 방식 같은 실제 작업 기준을 적으면 됩니다.

## 핵심 개념 2: skills
`skills`는 반복 작업 절차입니다.

쉽게 말하면 자주 하는 일을 위한 작업 설명서입니다.

예를 들어 매번 같은 방식으로 회의록을 정리하거나, 같은 형식의 안내문을 만들거나, 같은 스타일의 이미지를 만들 때 skill을 떠올릴 수 있습니다.

## skills를 언제 떠올리면 좋은가
- 같은 종류의 작업을 자주 할 때
- 매번 설명하는 절차가 비슷할 때
- 입력과 결과 형식이 어느 정도 정해져 있을 때
- 실수를 줄이고 결과 형식을 맞추고 싶을 때

지금은 skill을 완벽하게 만들 필요는 없습니다.

“반복 작업은 나중에 skill로 묶을 수 있다”는 감만 잡으면 충분합니다.

## 예시: 사진 기반 스케치 프로필 카드
`profile-sketch-card`는 사진과 재미용 학습 키워드를 받아 같은 스케치 노트 스타일의 프로필 카드를 만드는 예시입니다.

이 예시에서 중요한 것은 그림 자체가 아닙니다.

중요한 것은 사진과 키워드가 바뀌어도 비슷한 형식의 결과를 반복해서 만들 수 있다는 점입니다.

다만 실제 사람 사진을 사용할 때는 아래 기준을 지켜야 합니다.

- 당사자가 사용을 허락한 사진만 사용합니다.
- AI가 성격, 능력, 건강, 나이, 외모, 퍼스널컬러를 판단하게 하지 않습니다.
- 키워드는 분석 결과가 아니라 재미용 학습 태그라고 설명합니다.

## 함께 확인할 포인트
- `AGENTS.md`는 작업 기준입니다.
- `skills`는 반복 절차입니다.
- 둘 다 Codex를 더 일관되게 쓰기 위한 장치입니다.
- 처음부터 복잡하게 만들 필요는 없습니다.
- 작고 바로 확인 가능한 규칙부터 시작하면 됩니다.

## 각자 해보기
- `AI 해봄` 예시 작업공간의 루트 `AGENTS.md`를 다시 읽습니다.
- `raw/AGENTS.md`와 어떤 점이 다른지 한 문장으로 적어 봅니다.
- 개인 실습 폴더에 `AGENTS.md`가 없다면 만들 수 있다는 점을 기억합니다.
- 말투가 바로 바뀌는 쉬운 `AGENTS.md` 규칙을 직접 써 봅니다.
- 내 업무 폴더에 필요할 작업 규칙 한 줄을 생각해 봅니다.
- 반복해서 하고 싶은 업무 하나를 떠올리고, 나중에 skill로 묶을 수 있을지 생각해 봅니다.
