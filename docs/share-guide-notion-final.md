# AI 해봄 학습자료 공유 안내

## 이 자료는 무엇인가
이 자료는 AI 해봄 동호회에서 함께 보는 컬리큘럼 자료입니다.

AI 해봄의 목적은 단순히 AI 도구를 소개하는 것이 아닙니다.

각자 또는 각 부서에서 작은 업무자동화를 시작할 수 있도록 돕는 것입니다.

## 자료를 보는 방법
자료는 두 가지 방식으로 봅니다.

```text
Notion = 전체 안내와 목차
HTML = 실제 학습 화면
Markdown = 원문 보조 자료
```

처음에는 이 Notion 안내 페이지에서 시작합니다.

이후 회차별 HTML 시작 페이지를 열어 자료를 봅니다.

HTML 화면 안에서 `설명자료 열기`, `시연자료 열기`, `가이드 보기` 같은 버튼을 눌러 내용을 확인합니다.

필요할 때만 Markdown 원문을 참고합니다.

## 집에서 실습하는 방법
모임 시간에는 시연, 설명, 질문 답변, 토론을 중심으로 합니다.

실습은 각자 집에서 자료를 보며 진행합니다.

집에서 실습할 때는 아래 순서로 진행합니다.

1. 해당 회차 HTML 시작 페이지를 연다.
2. 설명자료를 먼저 읽는다.
3. 시연자료나 가이드를 같이 본다.
4. 본인 PC에서 따라 해 본다.
5. 막힌 지점을 기록한다.
6. 다음 모임이나 동호회 채널에서 질문한다.

## 막혔을 때 질문하는 방법
막혔을 때는 “안 됩니다”라고만 말하면 도와주기 어렵습니다.

아래 형식으로 질문하면 더 빨리 도울 수 있습니다.

```text
어느 회차 자료를 보고 있었는지:
어느 단계에서 막혔는지:
화면에 나온 문구:
내가 입력한 요청:
원하는 결과:
첨부할 수 있는 화면이나 파일명:
```

예시입니다.

```text
어느 회차 자료를 보고 있었는지: 6회차 Git 자료
어느 단계에서 막혔는지: git commit 실행
화면에 나온 문구: user.name 설정이 필요하다는 문구
내가 입력한 요청: git commit -m "첫 Git 연습 기록"
원하는 결과: 커밋이 정상적으로 남는 것
첨부할 수 있는 화면이나 파일명: git-practice.md
```

## 자료 사용 시 주의사항
- 내부자료를 외부 서비스에 무단 업로드하지 않습니다.
- 개인정보, 민감정보, 내부 의사결정 내용은 공유 자료에 넣지 않습니다.
- AI가 만든 결과는 초안으로 보고 담당자가 확인합니다.
- 실제 업무에 적용하기 전에는 결과가 맞는지 사람이 검토합니다.
- 원본 자료는 수정하지 않고 별도 폴더에 보관합니다.
