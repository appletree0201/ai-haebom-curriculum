# 1회차

## 오늘의 목표
- `VS Code`가 무엇을 하는 도구인지 이해한다.
- `Codex`가 작업공간 안에서 파일 작업을 도와주는 도구라는 점을 안다.
- 설치, 한글 설정, 확장 프로그램, 로그인, 권한 확인 흐름을 한 번 본다.
- 작은 요청을 보내고 결과를 확인하는 기본 흐름을 익힌다.
- `AGENTS.md`, `skills`, `세션`은 다음 회차부터 자세히 다룬다는 점만 안다.

## 먼저 알아둘 말
오늘은 복잡한 자동화를 만드는 날이 아닙니다.

오늘은 앞으로 실습을 하기 위한 작업 환경을 이해하는 날입니다.

설치를 현장에서 모두 끝내는 것보다, 집에서 혼자 다시 할 수 있도록 어디를 보고 무엇을 확인해야 하는지 아는 것이 중요합니다.

## 왜 이걸 배우는가
반복되는 업무는 생각보다 많습니다.

문서 정리, 파일 정리, 복사와 붙여넣기, 양식 맞추기, 결과 비교 같은 일은 시간이 많이 들고 실수도 생기기 쉽습니다.

AI와 코드를 함께 쓰면 이런 반복을 조금씩 줄일 수 있습니다.

`VS Code`와 `Codex`는 그 시작점입니다.

## 핵심 개념 1: VS Code
`VS Code`는 파일과 코드를 다루는 작업공간입니다.

처음에는 메모장처럼 보일 수 있지만, 실제로는 폴더를 열고, 파일을 만들고, 수정하고, 결과를 확인하는 작업실에 가깝습니다.

앞으로 Python, Markdown, Git, 자동화 실습을 할 때 모두 이 작업공간을 사용합니다.

## 핵심 개념 2: Codex
`Codex`는 자연어 요청을 바탕으로 파일 작업과 코드 작업을 도와주는 AI 도구입니다.

일반 ChatGPT처럼 문장을 고치는 것만 하는 도구가 아닙니다.

작업 폴더 안에 파일을 만들거나, 내용을 수정하거나, 결과를 확인하는 흐름에 함께 들어옵니다.

그래서 Codex를 쓸 때는 “어느 폴더에서”, “어떤 파일을”, “어떻게 바꿀지”를 작게 말하는 것이 좋습니다.

## 핵심 개념 3: 권한
Codex는 파일을 읽고 수정할 수 있기 때문에 권한 개념이 있습니다.

화면에서는 보통 아래와 같은 항목을 볼 수 있습니다.

- `기본 권한`
- `전체 액세스`
- `맞춤형(config.toml)`

1회차에서는 권한을 깊게 설정하지 않습니다.

어떤 메뉴가 있고, 권한 때문에 작업이 막힐 수 있다는 점만 이해하면 됩니다.

## 1회차에서 볼 자료
1회차는 세 가지 자료를 함께 사용합니다.

| 자료 | 역할 |
|---|---|
| 설명자료 | 도구의 역할과 전체 흐름 이해 |
| 설치 체크리스트 | 집에서 실제 설치와 확인을 진행 |
| 문제 해결 FAQ | 막혔을 때 증상별로 확인 |

설명자료를 읽고 전체 흐름을 이해한 뒤, 실제 설치는 체크리스트를 보며 진행합니다.

## 오늘의 흐름
1회차 모임에서는 아래 흐름을 화면으로 확인합니다.

1. VS Code 공식 다운로드 위치를 확인합니다.
2. 한글 언어팩 설치 위치를 봅니다.
3. 확장 프로그램 설치 위치를 봅니다.
4. 작업 폴더를 여는 이유를 이해합니다.
5. Codex 연결과 로그인 흐름을 봅니다.
6. 권한 메뉴 위치를 확인합니다.
7. 짧은 샘플 요청으로 파일이 만들어지는지 확인합니다.

## 샘플 요청
처음에는 AI가 내용을 지어내는 요청보다, 결과를 눈으로 확인하기 쉬운 양식을 만드는 요청이 좋습니다.

```text
현재 작업 폴더에 ai-haebom-practice.md 파일을 만들고, 1회차 실습 메모 양식을 만들어줘. 확인할 것에는 VS Code 실행, Codex 연결 확인, 새 파일 만들기를 체크박스로 넣어줘.
```

이 요청은 세 가지를 확인하게 해 줍니다.

- Codex가 응답하는지
- 작업 폴더 안에 `ai-haebom-practice.md` 파일이 생기는지
- 체크박스가 들어 있는 실습 메모 양식이 만들어지는지

## 함께 확인할 포인트
- 공식 사이트에서 다운로드해야 합니다.
- VS Code는 폴더를 열고 작업하는 도구입니다.
- 확장 프로그램은 필요한 기능을 추가하는 도구입니다.
- Codex는 작업 폴더 안의 파일을 만들거나 수정할 수 있습니다.
- 요청은 작게 하고, 결과를 바로 확인합니다.
- 막히면 화면 문구를 기록해야 도움을 받기 쉽습니다.

## 각자 해보기
- `https://code.visualstudio.com/`에 접속해 다운로드 위치를 확인합니다.
- VS Code를 실행합니다.
- 한글 언어팩 설치 여부를 확인합니다.
- 확장 프로그램 화면에서 `Python`, `Codex`, `Excel Viewer`를 검색해 봅니다.
- 실습 폴더를 열고 Codex 로그인 상태를 확인합니다.
- 샘플 요청으로 `ai-haebom-practice.md` 실습 메모 파일을 만들어 봅니다.
- 막힌 지점을 메모합니다.

## 마무리
1회차의 핵심은 세 가지입니다.

1. `VS Code`와 `Codex`의 역할을 이해합니다.
2. 설치와 연결에서 어디를 확인해야 하는지 압니다.
3. 작은 요청을 보내고 결과를 확인하는 흐름을 경험합니다.
