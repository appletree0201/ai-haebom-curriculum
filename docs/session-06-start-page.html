  • Windows에서 Git 설치 위치 확인

  • `init`, `status`, `add`, `commit` 실행 흐름 이해

6회차 현장 흐름

설치 확인부터 커밋까지 한 번에 많이 하지 않고, 상태를 계속 확인하면서 진행합니다.

Git 설치 Windows Git 설치 페이지에서 설치 파일을 받고 기본값으로 설치합니다.
설치 확인 VS Code를 다시 열고 터미널에서 `git --version`을 확인합니다.
파일 만들기 연습 폴더에서 `git-practice.md` 파일을 만들고 저장합니다.
기록 준비 `git init`, `git status`, `git add`로 기록할 파일을 준비합니다.
커밋 `git commit`으로 하나의 작업 기록을 남기고 다시 상태를 확인합니다.

각자 해보기

업무 폴더가 아니라 새 연습 폴더에서 오늘 명령어를 다시 실행합니다.

  • `git --version`으로 설치 여부를 확인합니다.
  • 새 연습 폴더를 하나 만듭니다.
  • `git-practice.md` 파일을 만들고 저장합니다.
  • `git init`, `git status`, `git add`, `git commit`을 다시 실행합니다.
  • `git status`를 여러 번 실행해 상태 변화를 봅니다.
  • 스테이징과 커밋의 차이를 한 문장으로 정리합니다.
