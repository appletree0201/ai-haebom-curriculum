# 6회차

## 오늘의 주제
오늘은 Windows PC에 Git을 설치하고, VS Code 터미널에서 기본 기록 남기기를 연습합니다.

5회차 자동화 과제 카드와 직접 연결하지 않습니다.

오늘은 별도 실습 파일인 `git-practice.md`로 Git의 기본 흐름만 익힙니다.

## 오늘의 목표
- Git이 무엇인지 아주 쉽게 이해한다.
- Windows에서 Git을 설치한다.
- VS Code 터미널에서 Git 설치 여부를 확인한다.
- `git-practice.md` 파일을 만든다.
- `git init`, `git status`, `git add`, `git commit`을 실행해 본다.
- 스테이징과 커밋의 차이를 이해한다.

## 오늘 다루지 않는 것
오늘은 Git의 가장 기본만 다룹니다.

아래 내용은 다루지 않습니다.

- GitHub
- branch
- merge
- conflict
- push
- pull
- 여러 사람이 함께 작업하는 협업 흐름

이 내용들은 나중에 필요해졌을 때 다룹니다.

## Git은 무엇인가
Git은 작업 기록을 남기는 도구입니다.

초보자는 이렇게 이해하면 됩니다.

```text
Git = 내 작업 폴더의 변경 기록 노트
```

파일을 만들거나 수정하면 Git이 그 변화를 확인할 수 있습니다.

그리고 내가 원할 때 그 상태를 하나의 기록으로 남길 수 있습니다.

Git을 쓰면 좋은 점은 아래와 같습니다.

- 무엇을 바꿨는지 볼 수 있다.
- 작업 단계를 기록으로 남길 수 있다.
- 실수했을 때 어디서 바뀌었는지 확인하기 쉽다.
- 나중에 자동화 과제 진행 과정을 설명하기 쉽다.

## 오늘 사용할 비유
오늘 Git 명령어는 아래처럼 이해합니다.

```text
git init = 이 폴더를 기록하기 시작
git status = 지금 뭐가 바뀌었는지 확인
git add = 이번 기록에 넣을 파일 고르기
git commit = 고른 파일들을 하나의 저장 기록으로 남기기
```

## 스테이징이란
`git add`를 설명하려면 스테이징을 알아야 합니다.

스테이징은 어렵게 생각하지 않아도 됩니다.

```text
스테이징 = 이번 저장 기록에 넣을 파일을 올려두는 대기 공간
```

예를 들어 파일 3개를 바꿨다고 해서 꼭 3개를 모두 한 번에 기록해야 하는 것은 아닙니다.

이번 기록에 넣고 싶은 파일만 고를 수 있습니다.

그 고르는 작업이 `git add`입니다.

## Windows에서 Git 설치하기
Git이 설치되지 않은 상태에서 시작합니다.

설치는 Windows 기준입니다.

1. 웹 브라우저를 연다.
2. Git 공식 설치 페이지에 접속한다.
3. Windows용 Git 설치 파일을 다운로드한다.
4. 다운로드한 설치 파일을 실행한다.
5. 특별한 이유가 없으면 기본값으로 `Next`를 눌러 진행한다.
6. 설치가 끝나면 VS Code를 완전히 닫았다가 다시 연다.

Git 공식 설치 페이지:

```text
https://git-scm.com/install/windows.html
```

회사 PC에서는 보안 정책 때문에 설치가 막힐 수 있습니다.

이 경우에는 무리하게 진행하지 말고 담당자나 관리자에게 문의합니다.

## 설치 확인하기
VS Code를 다시 연 뒤 터미널을 엽니다.

상단 메뉴에서 아래를 선택합니다.

```text
Terminal > New Terminal
```

터미널에서 아래 명령어를 입력합니다.

```text
git --version
```

정상이라면 아래처럼 Git 버전이 나옵니다.

```text
git version 2.xx.x
```

버전 숫자는 사람마다 다를 수 있습니다.

중요한 것은 `git version`이라는 문장이 나오는 것입니다.

## 실습 폴더 열기
Git은 폴더 단위로 기록을 남깁니다.

먼저 VS Code에서 실습 폴더를 엽니다.

1. VS Code에서 `File > Open Folder`를 누른다.
2. Git 연습용 폴더를 선택한다.
3. 왼쪽 `Explorer`에 폴더가 보이는지 확인한다.
4. 터미널이 그 폴더 위치에서 열려 있는지 확인한다.

처음에는 업무 폴더보다 별도 연습 폴더가 안전합니다.

예시 폴더 이름:

```text
git-practice
```

## 실습 파일 만들기
왼쪽 `Explorer`에서 새 파일을 만듭니다.

파일 이름은 아래처럼 합니다.

```text
git-practice.md
```

파일 내용은 간단히 작성합니다.

```md
# Git 연습

오늘 Git 설치와 기본 명령어를 배웠습니다.
```

저장합니다.

```text
Ctrl + S
```

## git init
이제 이 폴더를 Git으로 기록하기 시작합니다.

터미널에서 아래 명령어를 입력합니다.

```text
git init
```

의미는 아래와 같습니다.

```text
이 폴더를 Git 기록 대상으로 만들겠다.
```

한 번만 실행하면 됩니다.

## git status
현재 상태를 확인합니다.

```text
git status
```

Git이 현재 바뀐 파일을 알려 줍니다.

처음에는 `git-practice.md`가 아직 기록되지 않은 파일로 보일 수 있습니다.

초보자는 `git status`를 자주 입력해도 됩니다.

오히려 자주 확인하는 것이 좋습니다.

## git add
이번 기록에 넣을 파일을 고릅니다.

```text
git add git-practice.md
```

의미는 아래와 같습니다.

```text
git-practice.md 파일을 이번 기록에 넣을 준비를 하겠다.
```

이 상태가 스테이징입니다.

다시 상태를 확인합니다.

```text
git status
```

이제 파일이 커밋할 준비가 된 상태로 보입니다.

## git commit
준비한 파일을 하나의 기록으로 남깁니다.

```text
git commit -m "첫 Git 연습 기록"
```

의미는 아래와 같습니다.

```text
선택한 파일들을 "첫 Git 연습 기록"이라는 이름으로 저장 기록에 남기겠다.
```

커밋 메시지는 나중에 봐도 무엇을 했는지 알 수 있게 씁니다.

좋은 메시지 예시:

```text
첫 Git 연습 기록
자동화 과제 카드 초안 추가
문의 분류 예시 수정
```

## 다시 상태 확인하기
커밋 후 다시 확인합니다.

```text
git status
```

더 이상 변경된 내용이 없다고 나오면 정상입니다.

표현은 환경에 따라 조금 다를 수 있지만, 핵심은 아래입니다.

```text
기록할 변경사항이 남아 있지 않다.
```

## 오늘의 전체 흐름
오늘 실습 흐름은 아래와 같습니다.

```text
Git 설치
-> git --version
-> git-practice.md 만들기
-> git init
-> git status
-> git add git-practice.md
-> git status
-> git commit -m "첫 Git 연습 기록"
-> git status
```

## 자주 막히는 지점
### git 명령어를 찾을 수 없다고 나오는 경우
Git 설치가 안 되었거나, 설치 후 VS Code를 다시 열지 않은 경우가 많습니다.

VS Code를 완전히 닫았다가 다시 엽니다.

그래도 안 되면 PC를 재부팅하거나 설치 상태를 확인합니다.

### commit에서 이름과 이메일을 요구하는 경우
Git이 기록 작성자를 알 수 없어서 묻는 것입니다.

이 경우 아래 설정이 필요할 수 있습니다.

```text
git config --global user.name "내 이름"
git config --global user.email "내 이메일"
```

회사 기준이 있으면 회사 기준을 따릅니다.

### 터미널 위치가 다른 경우
현재 터미널이 실습 폴더 위치가 아닐 수 있습니다.

VS Code에서 실습 폴더를 다시 열고 새 터미널을 엽니다.

## 집에서 할 일
- Git이 설치되어 있는지 `git --version`으로 확인한다.
- 새 연습 폴더를 하나 만든다.
- `git-practice.md` 파일을 만든다.
- `git init`, `git status`, `git add`, `git commit`을 다시 실행해 본다.
- `git status`를 여러 번 실행하면서 상태가 어떻게 바뀌는지 본다.
