# 8회차

## 오늘의 주제
오늘은 각자 또는 각 부서에서 진행 중인 업무자동화 과제를 공유합니다.

중심은 완성품 발표가 아닙니다.

어디까지 만들었는지, 어떤 도움이 필요한지, 누구와 같이 보면 좋을지 나누는 시간입니다.

## 오늘의 목표
- 업무자동화 과제의 현재 단계를 같은 기준으로 말한다.
- 미리 작성해 온 `지원·협업 요청 카드`를 공유한다.
- 동호회 차원에서 도울 수 있는 내용을 모은다.
- 같이 보면 좋은 사람이나 부서를 연결한다.
- 각 과제별 다음 행동 1개를 정한다.

## 먼저 알아둘 말
오늘은 평가 시간이 아닙니다.

완성된 결과물이 없어도 괜찮습니다.

중요한 것은 지금 어디까지 왔는지 말하고, 다음에 무엇을 하면 좋을지 정하는 것입니다.

```text
8회차 = 발표회가 아니라 지원·협업 연결 시간
```

## 오늘 준비해 온 것
8회차 전에 아래 협업카드를 미리 작성해 옵니다.

```text
과제 이름:
현재 단계:
도움이 필요한 부분:
함께하면 좋은 사람/부서:
```

오늘 현장에서 새로 길게 작성하지 않습니다.

작성해 온 내용을 짧게 공유하고, 필요한 도움을 같이 정리합니다.

## 현재 단계 5단계
진행 상황은 아래 5단계 중 하나로 말합니다.

```text
1단계: 아이디어만 있음
2단계: 입력 자료를 정함
3단계: 출력 결과 모양을 정함
4단계: Codex에게 요청해 본 기록이 있음
5단계: 일부라도 실행되는 결과가 있음
```

단계가 낮아도 문제가 아닙니다.

단계가 낮으면 다음에 무엇을 정해야 하는지 더 분명해집니다.

## 협업카드 항목 설명
### 과제 이름
무엇을 자동화하려는지 한 줄로 적습니다.

예시:

```text
홈페이지 문의 유형 분류와 답변 초안 정리
```

### 현재 단계
5단계 중 하나를 고릅니다.

예시:

```text
현재 단계: 4단계, Codex에게 요청해 본 기록이 있음
```

### 도움이 필요한 부분
막힌 지점을 구체적으로 적습니다.

예시:

```text
엑셀 파일에서 필요한 열만 뽑는 방법을 모르겠습니다.
```

```text
결과가 맞는지 확인하는 기준을 못 정했습니다.
```

### 함께하면 좋은 사람/부서
혼자 해결하기 어렵다면 같이 보면 좋은 사람이나 부서를 적습니다.

예시:

```text
원본 자료를 잘 아는 부서
결과를 실제로 사용할 담당자
엑셀 파일 구조를 아는 사람
```

## 좋은 공유 예시
아래처럼 말하면 듣는 사람이 바로 도울 수 있습니다.

```text
과제 이름: 홈페이지 문의 유형 분류와 답변 초안 정리
현재 단계: 4단계
도움이 필요한 부분: 분류 기준은 만들었는데, 답변 초안이 너무 길게 나옵니다.
함께하면 좋은 사람/부서: 실제 문의 답변을 해 본 담당자와 같이 보고 싶습니다.
```

좋은 점:
- 과제가 한 줄로 보인다.
- 현재 단계가 분명하다.
- 막힌 부분이 구체적이다.
- 누구와 보면 좋을지 드러난다.

## 좋지 않은 공유 예시
아래처럼 말하면 도와주기 어렵습니다.

```text
자동화를 하고 싶은데 잘 안 됩니다.
```

어려운 이유:
- 어떤 업무인지 알 수 없다.
- 어디까지 했는지 알 수 없다.
- 무엇이 필요한지 알 수 없다.
- 누가 도와야 할지 알 수 없다.

## 서로 도울 수 있는 방식
지원과 협업은 거창하지 않아도 됩니다.

아래 정도도 충분한 협업입니다.

- 원본 자료 예시를 같이 보기
- 입력 자료에서 필요한 항목 골라 주기
- 출력 결과 모양을 같이 정하기
- Codex에게 보낼 요청 문장 같이 다듬기
- 실행 결과가 맞는지 확인해 주기
- 실제 업무 담당자 관점에서 빠진 내용 알려 주기

## 지원·협업 연결하기
공유가 끝나면 아래 기준으로 연결합니다.

```text
비슷한 과제끼리 묶기
같은 자료를 쓰는 사람 연결하기
같은 부서나 비슷한 업무 담당자 연결하기
기술적으로 막힌 사람과 해결 경험이 있는 사람 연결하기
검토가 필요한 사람과 실제 사용자 연결하기
```

오늘 목표는 모든 문제를 해결하는 것이 아닙니다.

누가 누구와 무엇을 같이 볼지 정하는 것입니다.

## 오늘의 진행 순서
1. 8회차 목적을 확인한다.
2. 현재 단계 5단계를 짧게 복습한다.
3. 미리 작성해 온 협업카드를 준비한다.
4. 과제별로 현재 상태를 짧게 공유한다.
5. 도움이 필요한 부분을 따로 모은다.
6. 비슷한 과제나 같이 보면 좋은 사람을 연결한다.
7. 각 과제별 다음 행동 1개를 정한다.

## 1시간 운영안
```text
0~5분: 오늘 목적 설명
5~10분: 현재 단계 5단계 복습
10~35분: 협업카드 공유
35~50분: 지원·협업 연결
50~57분: 다음 행동 1개 정리
57~60분: 다음 회차 예고
```

## 오늘의 결과물
오늘 끝날 때 각 과제마다 아래 한 줄이 남아야 합니다.

```text
다음 행동:
```

예시:

```text
다음 행동: 답변 초안이 너무 긴 문제를 줄이기 위해 실제 답변 예시 5개를 모아 Codex에게 다시 요청한다.
```

```text
다음 행동: 엑셀 원본 파일에서 필요한 열 이름을 먼저 정리한다.
```

## 집에서 이어서 할 일
- 오늘 받은 의견을 협업카드에 반영한다.
- 다음 행동 1개를 실제로 해 본다.
- Codex에게 요청한 내용과 결과를 저장해 둔다.
- 막힌 지점이 있으면 화면, 파일명, 요청 문장을 함께 기록한다.

## 다음 회차 예고
9회차는 최신 AI 트렌드 공유 시간입니다.

세부 주제는 지금 확정하지 않습니다.

회차 직전에 그때 가장 화제가 되는 AI 주제를 골라, 초보자 기준으로 핵심 개념과 업무자동화 연결점을 봅니다.

## 마무리
8회차의 핵심은 혼자 만들던 과제를 동호회 안으로 꺼내는 것입니다.

업무자동화는 혼자 모든 것을 알아야만 시작할 수 있는 일이 아닙니다.

자료를 아는 사람, 업무를 아는 사람, 결과를 검토할 사람이 연결될수록 더 현실적인 자동화가 됩니다.
