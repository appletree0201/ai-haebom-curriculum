# 2회차 시연내용

## 시연 목적
2회차 시연은 `AGENTS.md`와 `skills`를 눈으로 확인하는 시간입니다.

설명자료에서 개념을 읽었다면, 시연내용에서는 실제 화면에서 아래 흐름을 확인합니다.

- `AGENTS.md`가 어디에 있는지 본다.
- 루트 규칙과 하위 폴더 규칙이 다를 수 있음을 본다.
- 없는 파일은 Codex에게 만들어 달라고 요청할 수 있음을 본다.
- skill은 반복 작업 절차라는 점을 예시로 본다.

## 준비 상태
- VS Code가 실행되어 있습니다.
- `AI 해봄` 예시 작업공간이 열려 있습니다.
- 루트 `AGENTS.md`와 `raw/AGENTS.md`를 열어 볼 수 있습니다.
- 개인 실습 폴더 예시를 하나 준비합니다.
- `profile-sketch-card` 예시는 동의된 사진 또는 샘플 이미지로만 보여줍니다.

## 진행 흐름
1. VS Code에서 `AI 해봄` 예시 작업공간을 보여줍니다.
2. 루트 `AGENTS.md`를 엽니다.
3. `raw/AGENTS.md`를 열어 루트 문서와 비교합니다.
4. 개인 실습 폴더에는 처음에 `AGENTS.md`가 없을 수 있음을 확인합니다.
5. Codex에게 쉬운 `AGENTS.md`를 만들어 달라고 요청합니다.
6. 새 규칙이 답변에 반영되는지 확인합니다.
7. `skills`를 반복 작업 절차로 설명합니다.
8. `profile-sketch-card` 예시로 같은 형식이 반복되는 모습을 봅니다.
9. 마지막에 오늘 기억할 점을 정리합니다.

## 화면에서 보여줄 것
### 1. 루트 AGENTS.md
왼쪽 파일 목록에서 루트 `AGENTS.md`를 엽니다.

화면에서 볼 점은 두 가지입니다.

- 이 파일은 사람이 읽을 수 있는 Markdown 문서입니다.
- 전체 작업공간의 기준을 담고 있습니다.

### 2. raw/AGENTS.md
`raw/AGENTS.md`를 엽니다.

화면에서 볼 점은 두 가지입니다.

- 원본 자료를 다룰 때는 별도 규칙이 있을 수 있습니다.
- 같은 작업공간 안에서도 폴더마다 기준이 달라질 수 있습니다.

### 3. 개인 실습 폴더
개인 실습 폴더에는 처음에 `AGENTS.md`가 없을 수 있습니다.

이 상태는 오류가 아닙니다.

필요할 때 사람이 직접 만들거나 Codex에게 만들어 달라고 요청하면 됩니다.

## 요청 예시
### AGENTS.md 만들기
```text
현재 폴더에 AGENTS.md를 만들고, 아래 규칙 3개를 넣어줘.

- 항상 한국어로 대답한다.
- 초보자도 이해할 수 있게 쉽게 설명한다.
- 답변 마지막에 "오늘도 해봄!"을 붙인다.
```

### 규칙 적용 확인하기
```text
AGENTS.md에 적힌 규칙을 읽고, AGENTS.md가 무엇인지 한 문장으로 설명해줘.
```

확인할 점은 답변 마지막에 `오늘도 해봄!`이 붙는지입니다.

### 루트와 하위 규칙 비교하기
```text
루트 AGENTS.md와 raw/AGENTS.md의 역할 차이를 초보자 기준으로 한 문단으로 설명해줘.
```

확인할 점은 전체 규칙과 원본 자료 규칙을 구분해서 설명하는지입니다.

## skill 예시 보기
`profile-sketch-card` 예시는 skill이 반복 절차라는 점을 보여주기 위한 예시입니다.

시연 요청은 아래처럼 짧게 사용합니다.

```text
profile-sketch-card 스킬을 사용해서 이 사진을 바탕으로 스케치 노트 스타일의 프로필 카드 예시를 만들어줘.
키워드는 재미용 학습 태그로 정하고, 성격이나 외모 평가는 하지 마.
사진은 시각 참고용으로만 사용해줘.
```

확인할 점은 아래와 같습니다.

- 사진과 키워드는 바뀔 수 있습니다.
- 결과의 형식과 스타일은 비슷하게 유지됩니다.
- 사람을 평가하거나 분석하는 용도로 쓰지 않습니다.

## 결과 확인 기준
- `AGENTS.md`가 실제 파일로 만들어졌는지 확인합니다.
- 문서 안에 요청한 규칙이 들어갔는지 확인합니다.
- Codex 답변이 새 규칙을 따르는지 확인합니다.
- 루트 규칙과 하위 폴더 규칙을 구분해서 설명하는지 확인합니다.
- skill 예시에서 같은 형식이 반복되는지 확인합니다.

## 함께 확인할 포인트
- `AGENTS.md`는 자동으로 생긴다고 가정하지 않습니다.
- 파일이 없다면 만들 수 있습니다.
- 처음에는 말투 규칙처럼 바로 확인되는 예시가 좋습니다.
- 실제 업무에서는 말투보다 저장 위치, 원본 보호, 검토 기준 같은 규칙이 더 중요합니다.
- `skills`는 반복 작업 절차입니다.
- 실제 사람 사진을 쓸 때는 동의와 안전 기준을 먼저 확인합니다.

## 마무리 질문
시연을 본 뒤 아래 질문에 답해 봅니다.

- 내 개인 실습 폴더에 `AGENTS.md`가 없다면 어떻게 할 수 있나요?
- 루트 `AGENTS.md`와 하위 폴더 `AGENTS.md`는 왜 다를 수 있나요?
- 반복해서 하는 업무를 skill로 묶는다면 어떤 업무가 좋을까요?
