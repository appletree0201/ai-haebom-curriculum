# 4회차 시연내용

## 시연 목적
4회차 시연은 실제 업무자동화 작업본의 흐름을 보여주는 시간입니다.

목적은 기술 설명이 아니라, 질문이 들어와서 분류되고 답변 초안이 만들어지는 과정을 눈으로 확인하는 것입니다.

## 준비 상태
- 홈페이지 문의 자동화 작업본을 열 수 있습니다.
- 샘플 질문이 준비되어 있습니다.
- 분류 결과와 답변 초안을 확인할 화면이 준비되어 있습니다.
- 실제 개인정보나 민감정보가 들어간 자료는 사용하지 않습니다.

## 진행 흐름
1. 샘플 질문을 보여줍니다.
2. 자동 분류 결과를 확인합니다.
3. 답변 초안 생성 결과를 확인합니다.
4. 사람이 검토해야 할 부분을 짚습니다.
5. 자동화가 도와주는 부분과 사람이 판단할 부분을 나눕니다.

## 화면에서 보여줄 것
### 1. 샘플 질문
```text
정밀안전진단 보수교육이 승급교육으로 인정이 될까요?
```

확인할 점은 질문 안에 핵심 키워드가 있다는 것입니다.

### 2. 자동 분류
```text
승급교육 대상·대체인정
```

확인할 점은 자동화가 질문을 유형으로 나눈다는 것입니다.

### 3. 답변 초안
답변 초안이 생성되는 화면을 보여줍니다.

확인할 점은 초안이 바로 최종 답변이 아니라는 것입니다.

### 4. 사람의 확인
담당자가 확인해야 할 부분을 표시합니다.

- 법령이나 기준이 맞는지
- 교육 인정 조건이 정확한지
- 답변 문구가 너무 단정적이지 않은지
- 추가 문의 안내가 필요한지

## 결과 확인 기준
- 질문이 의도한 유형으로 분류되었는지 확인합니다.
- 답변 초안이 질문에 맞게 작성되었는지 확인합니다.
- 담당자가 검토해야 할 위험한 부분이 드러나는지 확인합니다.
- 자동화가 사람의 판단을 대체하지 않는다는 점이 보이는지 확인합니다.

## 함께 확인할 포인트
- 자동화는 반복 작업을 줄이는 도구입니다.
- 답변 초안은 검토 전 결과입니다.
- 자동화보다 중요한 것은 확인 기준입니다.
- 내 업무에서도 입력, 분류, 초안, 확인 구조를 찾을 수 있습니다.

## 마무리 질문
- 우리 부서에서 반복적으로 들어오는 질문은 무엇인가요?
- 그 질문은 어떤 유형으로 나눌 수 있나요?
- 자동화가 초안을 만들면 사람이 무엇을 확인해야 하나요?
