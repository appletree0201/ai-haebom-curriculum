# 4회차 시연자료

## 시연 목적
- 실제 업무자동화 작업본을 보여 준다.
- 홈페이지 문의가 `분류`와 `답변 초안`으로 바뀌는 흐름을 보여 준다.
- AI가 확정 답변을 하는 것이 아니라 담당자가 검토할 초안을 만든다는 점을 강조한다.
- 3회차의 플랜모드 흐름이 실제 자동화 구현으로 이어지는 모습을 보여 준다.

## 오늘 보여줄 핵심
오늘의 핵심은 아래 흐름입니다.

```text
홈페이지 문의
-> 문의 유형 분류
-> 답변 초안 생성
-> 담당자 확인
```

자동화가 모든 일을 끝내는 것이 아닙니다.

반복되는 판단과 초안 작성을 줄여 주고, 마지막 확인은 사람이 합니다.

## 시연 전 안내 멘트
아래처럼 안내합니다.

```text
오늘은 회원들이 만든 자동화를 발표하는 시간이 아닙니다.
AI 해봄에서 실제로 만들고 있는 업무자동화 작업본을 보면서,
자동화가 어떤 방식으로 만들어지는지 보는 시간입니다.
```

## 기존 업무 흐름
자동화 전에는 담당자가 이렇게 일합니다.

1. 홈페이지 문의를 읽는다.
2. 어떤 유형의 문의인지 판단한다.
3. 관련 기준이나 안내 문구를 찾는다.
4. 답변 초안을 작성한다.
5. 최종 답변으로 보내도 되는지 확인한다.

반복되는 부분은 `읽기`, `분류하기`, `초안 쓰기`입니다.

## 자동화 후 흐름
자동화 후에는 아래처럼 바뀝니다.

1. 질문을 입력한다.
2. AI가 문의 유형을 분류한다.
3. AI가 답변 초안을 작성한다.
4. 담당자가 분류와 초안을 확인한다.
5. 담당자가 필요한 부분을 수정한다.

## 시연용 질문
아래 질문을 사용합니다.

```text
정밀안전진단 보수교육이 승급교육으로 인정이 될까요
```

이 질문은 실제 업무 문의처럼 보입니다.

그리고 바로 확정 답변을 하면 위험한 질문입니다.

그래서 초안에는 `확인 필요` 관점이 들어가야 합니다.

## 시연 결과 예시
자동 분류 결과입니다.

```text
승급교육 대상·대체인정
```

답변 초안입니다.

```text
정밀안전진단 보수교육이 승급교육으로 인정되는지는 교육 종류, 이수 시기, 관련 법령, 제출 증빙자료에 따라 달라질 수 있습니다.

다른 법령에 따른 교육·훈련을 이수한 경우 일부 교육이 대체 인정될 수 있으나, 최종 인정 여부는 담당 부서의 확인이 필요합니다.

교육명, 이수기관, 이수일자, 수료증 등 관련 자료를 첨부하여 문의해 주시면 확인 후 안내드리겠습니다.
```

## 결과에서 확인할 점
시연 결과를 보면서 아래를 확인합니다.

- 질문 유형이 적절하게 분류되었는가
- 답변 초안이 너무 단정적으로 말하지 않는가
- 추가로 확인해야 할 정보를 요청하고 있는가
- 담당자가 검토하고 수정할 수 있는 형태인가

## 확정 표현과 안전한 표현 비교
위험한 표현입니다.

```text
정밀안전진단 보수교육은 승급교육으로 인정됩니다.
```

이 표현은 AI가 최종 판단을 한 것처럼 보입니다.

안전한 초안 표현입니다.

```text
정밀안전진단 보수교육이 승급교육으로 인정되는지는 교육 종류, 이수 시기, 관련 법령, 제출 증빙자료에 따라 달라질 수 있습니다.
최종 인정 여부는 담당 부서의 확인이 필요합니다.
```

업무자동화에서 중요한 것은 빠른 답변만이 아닙니다.

틀리면 안 되는 부분을 사람이 확인할 수 있게 남기는 것도 중요합니다.

## 3회차와 연결하기
이 자동화도 처음에는 큰 요청에서 시작할 수 있습니다.

```text
홈페이지 문의에 자동으로 답변하게 해줘.
```

하지만 바로 만들기에는 너무 큽니다.

플랜모드로 나누면 아래처럼 작아집니다.

```text
1. 어떤 문의 유형이 있는지 정한다.
2. 문의 예시를 유형별로 모은다.
3. 새 문의가 들어오면 유형을 분류한다.
4. 유형에 맞는 답변 초안을 만든다.
5. 확정 표현이나 위험한 문장을 점검한다.
6. 담당자가 최종 확인할 수 있게 결과를 보여준다.
```

## 시연 순서
1. 기존 업무 흐름을 보여 준다.
2. 자동화 후 흐름을 보여 준다.
3. 시연용 질문을 입력한다.
4. 자동 분류 결과를 확인한다.
5. 답변 초안을 확인한다.
6. 확정 표현과 안전한 표현을 비교한다.
7. AI가 한 일과 사람이 확인할 일을 나눈다.
8. 참가자 업무에도 비슷한 흐름이 있는지 질문한다.

## 화면에서 강조할 문장
```text
AI가 답변을 확정하는 것이 아닙니다.
담당자가 검토할 수 있는 초안을 빠르게 만드는 것입니다.
```

```text
자동화는 사람을 없애는 것이 아니라,
사람이 반복 초안보다 확인과 판단에 시간을 쓰게 만드는 것입니다.
```

## 참가자에게 던질 질문
- 우리 업무에도 들어오는 자료를 유형별로 나누는 일이 있는가?
- 반복해서 쓰는 안내 문구가 있는가?
- AI가 초안을 만들면 시간이 줄어들 부분은 어디인가?
- 사람이 반드시 확인해야 하는 부분은 무엇인가?
- 다음 5회차에 부서별 과제 카드로 정리해 볼 업무 후보는 무엇인가?

## 보조 샘플 요청
참가자가 집에서 비슷한 흐름을 연습할 때 쓸 수 있는 요청입니다.

```text
아래 문의를 읽고 유형을 분류해줘.
답변은 확정하지 말고, 담당자가 검토할 수 있는 초안으로 작성해줘.
추가 확인이 필요한 정보가 있으면 마지막에 적어줘.
```

```text
이 답변 초안에서 너무 단정적인 표현이 있는지 찾아줘.
더 안전한 표현으로 바꿔줘.
```

## 다음 5회차 준비 안내
시연 마지막에 아래처럼 안내합니다.

```text
다음 5회차에서는 각 부서에서 자동화하면 좋을 업무 후보를 공유하고,
Markdown으로 부서별 자동화 과제 카드를 작성합니다.

다음 모임 전까지 각 부서에서 반복되는 업무를 하나 이상 생각해 오세요.
```

생각해 올 때는 아래 4칸만 적어도 충분합니다.

```text
입력:
작업:
출력:
확인:
```

## 마무리
4회차 시연의 핵심은 실제 자동화 작업본을 통해 구조를 보는 것입니다.

질문을 받고, 유형을 나누고, 초안을 만들고, 사람이 확인하는 흐름을 이해하면 다른 업무에도 같은 사고방식을 적용할 수 있습니다.
