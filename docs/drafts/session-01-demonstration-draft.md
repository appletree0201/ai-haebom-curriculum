# 1회차 시연내용

## 시연 목적
1회차 시연은 `VS Code`와 `Codex`를 처음 보는 사람이 화면 흐름을 따라가게 하는 시간입니다.

설명을 많이 하기보다, 어디를 누르고 무엇을 확인하는지 보여주는 것이 목적입니다.

## 준비 상태
- 브라우저에서 `https://code.visualstudio.com/`에 접속할 수 있습니다.
- VS Code가 실행됩니다.
- 확장 프로그램 화면을 열 수 있습니다.
- Codex 연결과 로그인 상태를 확인할 수 있습니다.
- 실습용 작업 폴더가 준비되어 있습니다.
- 설치 체크리스트와 FAQ를 안내할 수 있습니다.

## 진행 흐름
1. VS Code 공식 다운로드 사이트를 보여줍니다.
2. VS Code 실행 화면을 보여줍니다.
3. 한글 언어팩 설치 위치를 보여줍니다.
4. 확장 프로그램 설치 위치를 보여줍니다.
5. 실습 폴더를 여는 모습을 보여줍니다.
6. Codex 연결과 로그인 상태를 확인합니다.
7. 권한 메뉴 위치를 보여줍니다.
8. 짧은 샘플 요청을 보냅니다.
9. 새 파일이 생겼는지 확인합니다.

## 화면에서 보여줄 것
### 1. VS Code 다운로드 위치
브라우저 주소창에 `https://code.visualstudio.com/`을 입력합니다.

확인할 점은 공식 사이트와 `Download for Windows` 버튼입니다.

### 2. VS Code 기본 화면
VS Code를 실행합니다.

확인할 점은 왼쪽 파일 목록, 가운데 편집 화면, 확장 프로그램 아이콘입니다.

### 3. 한글 언어팩
확장 프로그램 화면에서 `Korean Language Pack`을 검색합니다.

확인할 점은 설치 버튼과 설치 후 재시작 안내입니다.

### 4. 권장 확장
확장 프로그램 화면에서 아래 항목을 검색합니다.

- `Python`
- `Codex` 또는 `OpenAI Codex`
- `Excel Viewer`

확인할 점은 이름, 제공자, 설치 버튼입니다.

### 5. 작업 폴더
실습용 폴더를 엽니다.

확인할 점은 Codex가 어느 폴더 안에서 작업하는지입니다.

### 6. Codex 연결과 권한
Codex를 열고 로그인 상태를 확인합니다.

권한 메뉴에서 `기본 권한`, `전체 액세스`, `맞춤형(config.toml)` 항목이 보일 수 있음을 확인합니다.

## 요청 예시
처음 보여줄 요청은 아래 하나면 충분합니다.

```text
현재 작업 폴더에 YYYY-MM-DD 형식의 md 파일을 만들고, 오늘 배운 내용을 3개 항목으로 정리해줘.
```

## 결과 확인 기준
- Codex가 응답했는지 확인합니다.
- 작업 폴더 안에 날짜 형식의 `md` 파일이 생겼는지 확인합니다.
- 파일을 열었을 때 내용이 들어 있는지 확인합니다.
- 결과가 예상과 다르면 다시 짧게 수정 요청할 수 있음을 보여줍니다.

## 함께 확인할 포인트
- 오늘은 복잡한 자동화를 만드는 시간이 아닙니다.
- 설치와 연결 흐름을 눈으로 익히는 시간입니다.
- 요청은 작게 보냅니다.
- 결과를 반드시 확인합니다.
- 막히면 체크리스트와 FAQ를 먼저 봅니다.

## 마무리 질문
- 집에서 다시 할 때 가장 먼저 열어야 할 자료는 무엇인가요?
- Codex가 만든 파일은 어디에서 확인하나요?
- 막혔을 때 어떤 정보를 기록하면 도움을 받기 쉬울까요?
