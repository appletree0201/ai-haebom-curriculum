# 1회차 진행 및 시연 시나리오

## 진행 목적
1회차는 `VS Code`와 `Codex`를 처음 보는 회원들이 화면에 익숙해지는 시간입니다.

오늘의 목표는 설치를 완벽하게 끝내는 것이 아닙니다. 앞으로 AI에게 일을 부탁할 작업 공간이 어떻게 생겼는지 보고, 어디를 눌러야 하는지 한 번 따라가 보는 것입니다.

## 핵심 메시지
- `VS Code`를 개발자처럼 깊게 배우는 시간이 아닙니다.
- 오늘은 `Codex`와 함께 일하기 위한 기본 공간으로만 다룹니다.
- 모르는 화면이 나와도 정상입니다.
- 설치가 막히면 원인을 같이 확인하는 것도 실습입니다.
- 앞으로는 한 번에 큰 결과를 만들기보다 `작게 요청 -> 결과 확인 -> 조금 수정` 흐름으로 진행합니다.

## 진행 전 준비
- 진행자 PC에 `VS Code`가 설치되어 있습니다.
- 브라우저에서 `https://code.visualstudio.com/`을 열 수 있습니다.
- `Korean Language Pack`, `Python`, `Codex`, `Excel Viewer` 검색 화면을 보여줄 수 있습니다.
- Codex 로그인 또는 연결 상태를 보여줄 수 있습니다.
- 실습용 작업 폴더가 준비되어 있습니다.
- Notion 자료와 HTML 자료 링크를 바로 열 수 있습니다.
- 설치 체크리스트와 문제 해결 FAQ를 안내할 수 있습니다.

## 전체 시간 배분
| 시간 | 내용 | 진행 방식 |
|---|---|---|
| 0~5분 | 인사와 안심시키기 | 오늘의 목표 설명 |
| 5~10분 | 자료 안내 | Notion, HTML, PC 보기 권장 |
| 10~20분 | VS Code 소개 | 화면 구조와 다운로드 위치 시연 |
| 20~35분 | 설치와 확장 위치 | 한글 언어팩, 확장 프로그램 검색 |
| 35~50분 | Codex 연결과 샘플 요청 | 작업 폴더, 권한, 파일 생성 확인 |
| 50~57분 | 조편성 및 실습 방향 | 막힌 지점 공유, 조별 도움 흐름 |
| 57~60분 | 마무리 | 다음 회차 예고와 각자 해보기 |

## 0~5분: 시작 멘트
### 진행 멘트
```text
오늘은 VS Code와 Codex를 처음 연결해 보는 시간입니다.

오리엔테이션 때 VS Code 화면을 보시고 "이게 뭔가, 너무 개발자 도구 같은데"라고 느끼신 분들이 많으셨을 것 같습니다.

그렇게 느끼는 것이 자연스럽습니다. 오늘은 VS Code를 개발자처럼 깊게 배우려는 시간이 아닙니다.

우리는 VS Code를 AI에게 일을 부탁할 작업 공간으로만 사용할 예정입니다.
필요한 버튼과 흐름만 하나씩 보겠습니다.
```

### 강조할 점
- 오늘은 완성보다 흐름을 보는 날입니다.
- 설치가 늦어져도 문제 아닙니다.
- 화면이 다르게 보여도 당황하지 말고 문구를 같이 확인합니다.

## 5~10분: 자료 안내
### 화면에서 보여줄 것
1. Notion 안내 페이지
2. HTML 시작 페이지
3. 설치 체크리스트
4. 문제 해결 FAQ

### 진행 멘트
```text
자료는 Notion으로 먼저 공유드렸습니다.
Notion이 어렵거나 화면이 불편하신 분은 HTML 자료를 보시면 됩니다.

가능하면 PC에서 자료를 열어 보시는 것을 권장드립니다.
휴대폰으로 볼 수는 있지만, 설치 화면을 따라가기는 PC가 훨씬 편합니다.

이번 자료도 AI와 함께 준비했습니다.
표현이 어색하거나 설명이 부족한 부분은 모임에서 같이 확인하고 다듬어 보겠습니다.
```

## 10~20분: VS Code 화면 소개
### 화면에서 보여줄 것
1. 브라우저에서 `https://code.visualstudio.com/` 접속
2. `Download for Windows` 버튼 위치
3. VS Code 실행 화면
4. 왼쪽 파일 목록
5. 가운데 편집 화면
6. 왼쪽 확장 프로그램 아이콘

### 진행 멘트
```text
VS Code는 앞으로 우리가 작업할 책상이라고 생각하시면 됩니다.

처음에는 복잡해 보이지만 오늘 볼 곳은 많지 않습니다.
왼쪽은 파일과 기능을 고르는 곳이고, 가운데는 내용을 보는 곳입니다.
Codex는 이 작업 공간 안에서 파일을 만들거나 수정하는 일을 도와줍니다.
```

### 확인 질문
- "왼쪽 파일 목록이 보이시나요?"
- "확장 프로그램 아이콘 위치가 보이시나요?"
- "가운데 편집 화면이 어디인지 보이시나요?"

## 20~35분: 설치와 확장 프로그램 위치
### 화면에서 보여줄 것
1. 한글 언어팩 검색: `Korean Language Pack`
2. Python 확장 검색: `Python`
3. Codex 확장 또는 앱 연결 위치 확인
4. Excel/CSV 보기용 확장 검색: `Excel Viewer`

### 진행 멘트
```text
오늘 확장 프로그램을 전부 외우실 필요는 없습니다.

중요한 것은 "필요한 기능은 확장 프로그램에서 검색해서 추가한다"는 점입니다.
한글 메뉴가 필요하면 Korean Language Pack을 찾고,
앞으로 Python 자동화를 할 때는 Python 확장을 확인하고,
엑셀이나 CSV를 볼 때는 Excel Viewer 같은 확장을 사용할 수 있습니다.
```

### 막혔을 때 대응
- 설치 버튼이 보이지 않으면 이미 설치된 상태인지 확인합니다.
- 검색 결과가 많으면 이름과 제공자를 같이 봅니다.
- 재시작 안내가 나오면 "이런 안내가 나올 수 있다" 정도만 설명합니다.

## 35~50분: Codex 연결과 샘플 요청
### 화면에서 보여줄 것
1. 실습용 작업 폴더 열기
2. Codex 열기
3. 로그인 또는 연결 상태 확인
4. 권한 관련 메뉴 위치 확인
5. 샘플 요청 입력
6. 생성된 파일 확인

### 진행 멘트
```text
Codex는 그냥 대화만 하는 AI가 아니라, 지금 열어 둔 작업 폴더 안에서 파일을 만들고 고칠 수 있는 도구입니다.

그래서 먼저 어느 폴더를 열었는지가 중요합니다.
AI에게 부탁하기 전에 "어디에서 작업하는지"를 정해 주는 것입니다.
```

### 권한 설명 멘트
```text
Codex는 파일을 읽고 수정할 수 있기 때문에 권한 확인이 나올 수 있습니다.
오늘은 권한을 깊게 다루지는 않습니다.

다만 작업이 막힐 때 권한 문제일 수 있다는 점, 그리고 화면에 나오는 문구를 기록해 두면 도움을 받기 쉽다는 점만 기억하시면 됩니다.
```

### 샘플 요청
```text
현재 작업 폴더에 ai-haebom-practice.md 파일을 만들고, 1회차 실습 메모 양식을 만들어줘. 확인할 것에는 VS Code 실행, Codex 연결 확인, 새 파일 만들기를 체크박스로 넣어줘.
```

### 결과 확인
1. Codex가 응답했는지 봅니다.
2. 왼쪽 파일 목록에 `ai-haebom-practice.md`가 생겼는지 봅니다.
3. 파일을 열어 체크박스가 들어 있는 실습 메모 양식인지 봅니다.
4. 빈칸을 직접 채워 넣을 수 있음을 보여줍니다.

### 수정 요청 예시
```text
방금 만든 파일에 "막혔던 점"이라는 제목을 추가하고, 아래에 빈 체크박스 3개를 넣어줘.
```

## 50~57분: 조편성과 실습 방향
### 진행 멘트
```text
오늘 이후에는 혼자 막히는 시간을 줄이기 위해 조를 나눠서 같이 확인하는 방식으로 진행하겠습니다.

잘하는 사람과 처음 보는 사람이 나뉘는 구조가 아니라,
화면이 다르게 나올 때 서로 캡처와 문구를 확인해 주는 구조입니다.
```

### 조별 확인 항목
- VS Code 설치 여부
- 한글 언어팩 설치 여부
- Codex 연결 여부
- 실습 폴더 열기 성공 여부
- 샘플 파일 생성 성공 여부
- 막힌 화면 문구

## 57~60분: 마무리
### 진행 멘트
```text
오늘의 핵심은 세 가지입니다.

첫째, VS Code는 앞으로 사용할 작업 공간입니다.
둘째, Codex는 그 작업 공간 안에서 파일 작업을 도와주는 AI입니다.
셋째, 요청은 작게 하고 결과를 바로 확인합니다.

다음 회차에서는 Codex가 작업할 때 어떤 규칙을 읽는지, AGENTS.md와 skills 개념을 가볍게 확인하겠습니다.
```

## 진행자가 기억할 것
- 설명보다 화면 확인을 우선합니다.
- 모르는 용어를 길게 설명하지 않습니다.
- 참여자가 당황하면 "처음 보면 낯선 화면이 맞다"고 먼저 말합니다.
- 모든 설치 문제를 현장에서 해결하려고 하지 않습니다.
- 막힌 화면, 오류 문구, 설치 상태를 기록하게 합니다.
- 다음 회차로 넘길 문제와 현장에서 해결할 문제를 구분합니다.

## 현장 질문 대응 문구
### "저는 코딩을 몰라서 어려울 것 같습니다"
```text
오늘은 코딩을 배우는 시간이 아닙니다.
AI에게 일을 부탁할 작업 공간을 여는 연습부터 시작합니다.
코드는 나중에 필요한 만큼만 보게 됩니다.
```

### "화면이 제 것과 다릅니다"
```text
괜찮습니다. 설치 버전이나 설정에 따라 화면이 조금 다를 수 있습니다.
버튼 이름과 화면 문구를 기준으로 같이 찾아보겠습니다.
```

### "설치가 안 되면 오늘 못 따라가나요?"
```text
아닙니다. 오늘은 진행자 화면을 보면서 흐름을 이해하셔도 됩니다.
설치는 체크리스트를 보고 나중에 다시 해도 됩니다.
```

### "Notion이 어렵습니다"
```text
같은 내용을 HTML 자료로도 제공드립니다.
자료를 보는 도구 때문에 실습이 막히지 않도록 두 가지 경로를 준비했습니다.
```

## 각자 해보기 안내
- 집에서 PC로 HTML 시작 페이지를 다시 엽니다.
- 설치 체크리스트를 보며 VS Code와 확장 프로그램을 확인합니다.
- Codex 연결 상태를 확인합니다.
- 샘플 요청으로 `ai-haebom-practice.md` 실습 메모 파일을 만들어 봅니다.
- 막힌 화면은 캡처하거나 문구를 적어 다음 모임 때 공유합니다.
