# 8회차 운영자료

## 운영 목적
- 참여자가 미리 작성해 온 협업카드를 공유하게 한다.
- 완성품 평가 분위기가 되지 않도록 한다.
- 과제별 현재 단계와 도움이 필요한 부분을 분명히 한다.
- 동호회 차원에서 지원이나 협업이 필요한 내용을 모은다.
- 각 과제별 다음 행동 1개를 정한다.

## 오늘 하지 않을 것
```text
새 도구 강의
새 자동화 예제 구현
완성품 평가
잘한 사람과 못한 사람 구분
```

오늘은 진행 상황을 꺼내고 같이 도울 지점을 찾는 시간입니다.

## 시작 멘트
아래처럼 시작합니다.

```text
오늘은 완성품 발표가 아닙니다.
각자 또는 각 부서에서 진행 중인 자동화 과제가 어디까지 왔는지 공유하고,
도움이 필요한 부분을 동호회 차원에서 같이 연결하는 시간입니다.
```

## 준비물 확인
참여자가 아래 카드를 미리 작성해 왔는지 확인합니다.

```text
과제 이름:
현재 단계:
도움이 필요한 부분:
함께하면 좋은 사람/부서:
```

작성하지 못한 사람이 있으면 현장에서 길게 쓰게 하지 않습니다.

아래 두 가지만 먼저 말하게 합니다.

```text
무엇을 자동화하려고 하나요?
지금 가장 막힌 부분은 무엇인가요?
```

## 현재 단계 5단계 안내
공유 전에 5단계를 다시 보여 줍니다.

```text
1단계: 아이디어만 있음
2단계: 입력 자료를 정함
3단계: 출력 결과 모양을 정함
4단계: Codex에게 요청해 본 기록이 있음
5단계: 일부라도 실행되는 결과가 있음
```

멘트:

```text
오늘은 높은 단계가 좋은 것이 아닙니다.
현재 단계를 정확히 말해야 다음 도움을 정할 수 있습니다.
```

## 공유 방식
한 과제당 2분 안쪽으로 공유합니다.

공유 순서는 아래와 같습니다.

```text
1. 과제 이름
2. 현재 단계
3. 도움이 필요한 부분
4. 함께하면 좋은 사람/부서
```

시간이 부족하면 자세한 설명보다 막힌 지점을 우선합니다.

## 진행자가 적어 둘 내용
공유를 들으면서 아래 내용을 따로 모읍니다.

```text
과제 이름:
현재 단계:
지원 필요:
연결 후보:
다음 행동:
```

이 기록은 10회차 중간 발표와 개선 때 다시 활용할 수 있습니다.

## 공유 예시
예시입니다.

```text
과제 이름: 교육 문의 답변 초안 정리
현재 단계: 4단계
도움이 필요한 부분: 답변 초안이 실제 안내문 말투와 맞지 않습니다.
함께하면 좋은 사람/부서: 실제 민원 답변을 자주 작성하는 담당자
```

진행자는 이렇게 되묻습니다.

```text
그럼 다음 행동은 실제 답변 예시 5개를 모아서 Codex에게 말투를 맞춰 달라고 요청하는 것으로 잡아도 될까요?
```

## 지원·협업 연결 질문
공유 후 아래 질문으로 연결합니다.

```text
이 과제와 비슷한 자료를 다루는 분이 있나요?
```

```text
이 결과물을 실제로 검토해 줄 수 있는 분이 있나요?
```

```text
같은 방식으로 자동화할 수 있는 다른 업무가 있나요?
```

```text
이 과제의 다음 요청 문장을 같이 다듬어 줄 분이 있나요?
```

## 다음 행동 정리
각 과제는 마지막에 반드시 다음 행동 1개를 남깁니다.

형식은 아래처럼 단순하게 합니다.

```text
다음 행동:
```

좋은 예시:

```text
다음 행동: 엑셀 원본 파일에서 필요한 열 이름을 정리한다.
```

```text
다음 행동: Codex에게 보낸 요청 문장과 결과 화면을 저장해 온다.
```

```text
다음 행동: 실제 사용자가 원하는 출력 예시를 1개 그려 온다.
```

## 1시간 진행 순서
```text
0~5분: 오늘 목적 설명
5~10분: 현재 단계 5단계 복습
10~35분: 협업카드 공유
35~50분: 지원·협업 연결
50~57분: 다음 행동 1개 정리
57~60분: 다음 회차 예고
```

## 마무리 멘트
```text
오늘 공유한 내용은 평가 결과가 아닙니다.
이제 각 과제가 혼자 하는 일이 아니라 동호회 안에서 같이 다듬을 수 있는 일이 되었습니다.
다음 행동 1개만 실제로 해 보면 됩니다.
```
