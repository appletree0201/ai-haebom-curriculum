# 3회차 시연내용

## 시연 목적
3회차 시연은 막연한 요청이 질문을 거쳐 실행 가능한 계획으로 바뀌는 과정을 보여줍니다.

코드를 작성하는 장면보다 요청이 정리되는 과정을 보는 것이 중요합니다.

## 준비 상태
- 플랜모드 또는 계획 수립 대화가 가능한 Codex 화면이 준비되어 있습니다.
- 예시 요청 한 문장을 준비합니다.
- 입력, 작업, 출력, 확인 기준을 적어 볼 수 있는 메모 파일을 준비합니다.

## 진행 흐름
1. 막연한 큰 요청을 입력합니다.
2. AI가 되묻는 질문을 확인합니다.
3. 질문에 짧게 답합니다.
4. 입력, 작업, 출력, 확인 기준으로 정리합니다.
5. 실행 가능한 작은 요청으로 바꿉니다.
6. 계획을 저장할 md 파일을 만듭니다.

## 화면에서 보여줄 것
### 1. 큰 요청 입력
```text
엑셀 명단을 보기 좋게 정리하고 싶어요.
```

확인할 점은 이 요청만으로는 기준이 부족하다는 것입니다.

### 2. AI의 질문 확인
AI가 어떤 파일, 어떤 기준, 어떤 결과, 어떤 확인 방법이 필요한지 묻는지 봅니다.

확인할 점은 질문이 귀찮은 절차가 아니라 계획을 만드는 과정이라는 것입니다.

### 3. 답변으로 기준 채우기
아래처럼 짧게 답합니다.

```text
파일: 회원 명단 엑셀
기준: 직급별, 부서별
결과: md 요약 표
확인: 전체 합계가 원본 인원 수와 같은지
```

### 4. 작은 요청으로 바꾸기
```text
회원 명단 엑셀을 읽고 직급별 인원과 부서별 인원을 계산한 뒤,
요약 표를 md 파일로 만들어줘.
전체 합계가 원본 명단 인원 수와 같은지도 확인해줘.
```

## 결과 확인 기준
- 큰 요청과 작은 요청의 차이가 보이는지 확인합니다.
- 입력, 작업, 출력, 확인 기준이 모두 들어갔는지 확인합니다.
- 계획을 저장한 md 파일이 생겼는지 확인합니다.
- 바로 실행하지 않고 계획부터 세웠는지 확인합니다.

## 함께 확인할 포인트
- 질문을 받는 것은 실패가 아닙니다.
- 질문에 답할수록 요청이 좋아집니다.
- 큰 업무도 작은 기준으로 나누면 시작할 수 있습니다.
- 계획은 나중에 구현할 때 다시 사용할 수 있습니다.

## 마무리 질문
- 지금 내 업무에서 큰 요청으로 시작할 만한 일은 무엇인가요?
- 그 요청의 입력 자료는 무엇인가요?
- 결과가 맞는지 어떻게 확인할 수 있나요?
