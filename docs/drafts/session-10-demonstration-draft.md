# 10회차 운영자료

## 운영 목적
- 10회차를 끝맺음 발표가 아니라 시작점 공유회로 운영한다.
- 참여자가 현재 상태와 느낀 점을 부담 없이 공유하게 한다.
- 완성 여부보다 배움, 가능성, 위험한 점을 함께 본다.
- 발표 후 아이디어 확장 질문으로 과제를 앞으로 키울 방향을 넓힌다.
- 10회 이후에도 동호회 활동이 이어진다는 메시지를 남긴다.

## 오늘 하지 않을 것
```text
최종 성과 평가
완성품 순위 매기기
구체적인 다음 행동 강제
실패한 과제 지적
기술 수준 비교
```

오늘은 과제를 끝내는 날이 아닙니다.

각자의 업무자동화가 앞으로 어디로 자랄 수 있는지 보는 날입니다.

## 시작 멘트
아래처럼 시작합니다.

```text
오늘은 10회차이지만 끝이 아닙니다.
지금까지는 도구를 익히고, 과제를 찾고, 작게 시도해 보는 준비 과정이었습니다.
이제부터 각자의 업무자동화가 실제 업무 안에서 시작됩니다.
```

이어 말합니다.

```text
완성품이 없어도 괜찮습니다.
오늘은 현재 상태, 써 본 느낌, 막힌 점, 앞으로의 가능성을 공유하는 시간입니다.
```

## 공유 항목 안내
각 과제는 아래 5가지만 공유합니다.

```text
1. 과제 이름
2. 현재 결과물 또는 진행 상태
3. 실제로 써 보니 좋았던 점
4. 막힌 점 또는 위험한 점
5. 느낀 점
```

멘트:

```text
다음 개선 행동을 구체적으로 확정하지 않아도 됩니다.
동호회 활동은 10회차에서 끝나지 않기 때문입니다.
```

## 과제별 공유 진행 방식
한 과제당 3분 안쪽으로 공유합니다.

시간이 부족하면 아래 3가지를 우선합니다.

```text
현재 어디까지 왔나요?
써 보니 무엇이 좋았나요?
무엇이 위험하거나 막혔나요?
```

결과물이 있으면 화면을 보여 줍니다.

결과물이 없으면 과제 카드, 요청 문장, 입력 자료, 출력 예시 중 하나만 보여 줘도 됩니다.

## 진행자가 적어 둘 내용
공유를 들으면서 아래 내용을 간단히 적습니다.

```text
과제 이름:
현재 상태:
좋았던 점:
막힌 점/위험한 점:
느낀 점:
확장 아이디어:
```

이 기록은 10회 이후 동호회 활동을 이어갈 때 참고합니다.

## 좋은 시작점 공유 예시
예시입니다.

```text
과제 이름: 교육 문의 답변 초안 정리
현재 결과물 또는 진행 상태: 문의 문장을 넣으면 분류와 답변 초안이 나오는 형태까지 해 봤습니다.
실제로 써 보니 좋았던 점: 반복해서 쓰는 안내 문장을 빨리 만들 수 있었습니다.
막힌 점 또는 위험한 점: 답변이 너무 확정적으로 나와서 담당자 확인이 꼭 필요합니다.
느낀 점: AI가 답을 대신한다기보다 초안을 빨리 만들어 주는 도구라는 느낌을 받았습니다.
```

## 아이디어 확장 질문 운영
발표가 끝나면 평가하지 않고 질문을 던집니다.

질문은 2~3개만 고릅니다.

```text
이 과제를 다른 부서에서도 쓸 수 있을까요?
```

```text
입력 자료를 바꾸면 다른 업무에도 적용될까요?
```

```text
사람이 확인해야 하는 부분은 어디까지 남겨야 할까요?
```

```text
이 과제를 더 작게 만들면 무엇부터 할 수 있을까요?
```

```text
나중에 다른 시스템과 연결한다면 어디가 좋을까요?
```

진행자는 답을 강요하지 않습니다.

아이디어가 나오면 “나중에 더 볼 수 있는 방향”으로만 적어 둡니다.

## 공통 인사이트 정리
여러 과제를 들은 뒤 반복되는 배움을 모읍니다.

예시:

```text
입력 자료 정리가 중요하다.
결과물 모양을 먼저 정하면 요청이 쉬워진다.
사람이 확인할 부분은 남겨야 한다.
처음부터 크게 만들면 막힌다.
작게 써 보고 고치는 흐름이 중요하다.
```

## 1시간 진행 순서
```text
0~5분: 10회차 목적 설명
5~10분: 공유 항목 5가지 설명
10~35분: 과제별 시작점 공유
35~50분: 아이디어 확장 질문
50~57분: 공통 인사이트 정리
57~60분: 이제부터 시작 메시지
```

## 마지막 멘트
아래 메시지로 끝냅니다.

```text
오늘 공유한 과제는 완성품이 아닙니다.
각자의 업무 안에서 계속 자라날 시작점입니다.
10회차는 끝이 아니라, 이제부터 업무자동화를 실제 업무 속에서 키워 가는 출발선입니다.
```
