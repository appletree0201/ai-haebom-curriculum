  • 루트와 하위 폴더 규칙 차이 확인
  • 한 줄 작업 규칙 예시 이해
  • `skills`를 반복 작업 절차로 이해
  • `profile-sketch-card` 예시로 반복성 확인

집에서 할 일

2회차 이후에는 Codex에게 무작정 요청하기보다, 어떤 기준과 절차가 필요한지 먼저 생각합니다.

  • `AI 해봄` 예시 작업공간의 루트 `AGENTS.md`를 다시 읽습니다.
  • `AI 해봄` 예시 작업공간의 `raw/AGENTS.md`와 어떤 점이 다른지 한 문장으로 적습니다.
  • 내 개인 실습 폴더에 `AGENTS.md`가 없다면 새로 만들 수 있다는 점을 기억합니다.
  • 말투가 바로 바뀌는 쉬운 `AGENTS.md` 규칙을 써 봅니다.
  • 익숙해지면 내 업무 폴더에 필요한 작업 규칙 한 줄을 생각해 봅니다.
  • `skills`를 “반복 작업 절차”라는 말로 다시 설명해 봅니다.
  • 반복해서 하고 싶은 업무를 하나 떠올립니다.
  • 그 업무를 skill로 만든다면 어떤 입력과 결과가 필요할지 적어 봅니다.
