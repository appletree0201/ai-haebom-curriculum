# 1회차 설치 체크리스트

## 목적
이 체크리스트는 집에서 혼자 `VS Code` 설치와 기본 설정을 완료하기 위한 자료입니다.

마지막에 날짜 형식의 `md` 파일이 하나 만들어지면 1회차 실습 성공입니다.

## 1. VS Code 다운로드
- [ ] 브라우저를 엽니다.
- [ ] 주소창에 `https://code.visualstudio.com/`을 입력합니다.
- [ ] 공식 `Visual Studio Code` 사이트가 열렸는지 확인합니다.
- [ ] `Download for Windows` 버튼을 누릅니다.
- [ ] 설치 파일이 다운로드되었는지 확인합니다.

## 2. VS Code 설치
- [ ] 다운로드한 설치 파일을 실행합니다.
- [ ] 특별한 이유가 없으면 기본값으로 설치합니다.
- [ ] 설치가 끝나면 `Visual Studio Code`를 실행합니다.
- [ ] 프로그램 화면이 열리는지 확인합니다.

## 3. 한글 언어팩 설치
- [ ] 왼쪽 사이드바에서 `Extensions` 아이콘을 누릅니다.
- [ ] 검색창에 `Korean Language Pack`을 입력합니다.
- [ ] `Korean Language Pack for Visual Studio Code`를 찾습니다.
- [ ] `Install` 버튼을 누릅니다.
- [ ] 다시 시작 안내가 나오면 `Restart`를 누릅니다.
- [ ] 다시 열린 뒤 메뉴가 한글로 보이는지 확인합니다.

## 4. 기본 확장 프로그램 설치
확장 프로그램은 모두 왼쪽 `Extensions` 화면에서 검색합니다.

- [ ] `Python`을 검색합니다.
- [ ] 이름과 제공자를 확인하고 `Python` 확장을 설치합니다.
- [ ] `Codex` 또는 `OpenAI Codex`를 검색합니다.
- [ ] `AI 해봄` 안내 화면과 이름 및 제공자를 비교한 뒤 Codex 관련 확장을 설치합니다.
- [ ] `Excel Viewer` 또는 엑셀/CSV 미리보기 확장을 검색합니다.
- [ ] 엑셀 파일이나 CSV 파일을 VS Code에서 확인할 수 있는 확장을 설치합니다.
- [ ] 필요하면 `Markdown All in One`을 검색해 설치합니다.

## 5. 작업 폴더 열기
- [ ] 실습에 사용할 폴더를 하나 정합니다.
- [ ] `VS Code`에서 `File` 또는 `파일` 메뉴를 엽니다.
- [ ] `Open Folder` 또는 `폴더 열기`를 선택합니다.
- [ ] 실습 폴더를 엽니다.
- [ ] 왼쪽에 폴더와 파일 목록이 보이는지 확인합니다.

## 6. Codex 로그인 확인
- [ ] `VS Code`에서 Codex를 엽니다.
- [ ] 로그인이 필요한 경우 계정으로 로그인합니다.
- [ ] 로그인 후 Codex 입력창이나 연결 상태가 보이는지 확인합니다.
- [ ] 오류 메시지가 나오면 내용을 먼저 읽습니다.

## 7. 권한 확인
- [ ] Codex 권한 메뉴를 엽니다.
- [ ] `기본 권한`이 보이는지 확인합니다.
- [ ] `전체 액세스`가 보이는지 확인합니다.
- [ ] `맞춤형(config.toml)`이 보이는지 확인합니다.
- [ ] 처음에는 권한 이름과 위치만 확인합니다.

## 8. 샘플 md 파일 생성
Codex에 아래 요청을 입력합니다.

```text
현재 작업 폴더에 YYYY-MM-DD 형식의 md 파일을 만들고, 오늘 배운 내용을 3개 항목으로 정리해줘.
```

- [ ] Codex가 응답하는지 확인합니다.
- [ ] 왼쪽 파일 목록에 날짜 형식의 `md` 파일이 생겼는지 확인합니다.
- [ ] 파일을 열어 내용이 들어 있는지 확인합니다.
- [ ] 파일 위치가 내가 연 작업 폴더 안인지 확인합니다.

## 완료 기준
아래 항목이 모두 되면 1회차 설치 실습은 완료입니다.

- [ ] `VS Code`가 실행된다.
- [ ] 메뉴가 한글로 보인다.
- [ ] `Python` 확장이 설치되어 있다.
- [ ] Codex 관련 확장이 설치되어 있다.
- [ ] 엑셀/CSV 보기용 확장이 설치되어 있다.
- [ ] Codex 로그인이 되어 있다.
- [ ] 날짜 형식의 `md` 파일이 작업 폴더 안에 생성되어 있다.
